📖 详细介绍

Ollama是目前最流行的本地大模型运行工具，把模型下载、量化、运行封装成一条命令。安装后执行ollama run qwen2即可对话。提供http://localhost:11434的REST API，任何程序都能通过HTTP调用。

🛠️ 详细部署 / 配置操作步骤

1

下载安装

访问ollama.com/download，选择对应系统版本下载安装。Windows版双击安装即可，安装后自动后台运行。
2

拉取模型

打开命令行执行 ollama pull qwen2 拉取通义千问2模型（约4.7GB）。
3

运行对话

执行 ollama run qwen2 即可在终端对话，输入/bye退出。
4

验证API

浏览器打开http://localhost:11434显示Ollama is running即正常。
5

开机自启

Windows版默认开机自启，Linux执行systemctl enable ollama。

🔁 exe / apk 内嵌与后端回调接通教程

内嵌到exe/apk的回调流程：客户端 → HTTP请求 → 收到JSON回复 → 解析内容 → 触发回调函数更新UI。注意API Key的安全存储，建议在服务端环境变量中管理。
Ollama回调函数模板python
import requests

def on_ai_reply(text):
    """回调函数：AI回答后调用此函数"""
    print("AI回答:", text)

def ask(prompt, model="qwen2"):
    r = requests.post("http://localhost:11434/api/generate",
        json={"model": model, "prompt": prompt, "stream": False}, timeout=120)
    reply = r.json()["response"]
    on_ai_reply(reply)
    return reply

ask("写一首关于秋天的诗")
