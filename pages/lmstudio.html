📖 详细介绍

LM Studio是一款图形化本地大模型运行工具，适合不熟悉命令行的用户。内置模型搜索和下载功能，支持加载GGUF格式模型，一键启动OpenAI兼容的API服务器。

🛠️ 详细部署 / 配置操作步骤

1

下载安装

访问lmstudio.ai下载安装包，双击安装。
2

搜索模型

打开软件，在左侧搜索栏输入模型名称（如qwen2）。
3

下载模型

点击模型卡片的Download按钮下载。
4

加载对话

切换到Chat页面，选择已下载的模型开始对话。
5

启动API

在Developer页面启动本地服务器，端口默认1234。

🔁 exe / apk 内嵌与后端回调接通教程

内嵌到exe/apk的回调流程：客户端 → HTTP请求 → 收到JSON回复 → 解析内容 → 触发回调函数更新UI。注意API Key的安全存储，建议在服务端环境变量中管理。
LM Studio回调函数模板python
import requests

# LM Studio默认端口1234，兼容OpenAI格式
def ask_lmstudio(prompt):
    r = requests.post("http://localhost:1234/v1/chat/completions",
        json={"model": "local-model", "messages": [{"role": "user", "content": prompt}]})
    return r.json()["choices"][0]["message"]["content"]

print(ask_lmstudio("你好"))
