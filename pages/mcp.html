🧠 它擅长什么

  • 统一大模型与外部工具的连接标准
  • 支持本地文件读写、数据库查询、API调用
  • 可被Claude Desktop、OpenClaw等客户端连接
  • 支持stdio和HTTP/SSE两种传输方式
  • 完全本地运行，数据不出本机

📖 详细介绍

MCP是由Anthropic提出的开放协议，标准化大语言模型与外部工具、数据源之间的连接方式。采用客户端-服务器架构，通过JSON-RPC协议通信。

🛠️ 详细部署步骤

1

安装环境

安装Node.js 18+和Python 3.10+，执行pip install mcp。
2

创建MCP服务

创建server.py，使用FastMCP框架定义工具函数。
3

启动服务

执行python server.py，默认通过stdio通信。
4

配置客户端

在支持MCP的客户端中添加服务，配置启动命令。
5

测试连接

在AI对话中请求调用工具，验证连接成功。
6

扩展工具

继续添加@mcp.tool()函数扩展AI能力。

🔁 exe/apk内嵌回调教程

MCP服务内嵌到exe/apk：应用启动MCP子进程 → stdio通信 → AI调用工具 → 返回JSON结果 → 回调函数更新UI。
MCP服务完整模板python
from mcp.server.fastmcp import FastMCP
import os, json

mcp = FastMCP("local-tools")

@mcp.tool()
def read_file(path: str) -> str:
    """读取本地文件内容"""
    with open(path, "r", encoding="utf-8") as f:
        return f.read()

@mcp.tool()
def write_file(path: str, content: str) -> str:
    """写入文件"""
    with open(path, "w", encoding="utf-8") as f:
        f.write(content)
    return "已写入"

if __name__ == "__main__":
    mcp.run()
